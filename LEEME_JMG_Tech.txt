CÓMO REEMPLAZAR EL ARCHIVO
1. Descarga y extrae el ZIP.
2. Abre el repositorio de arriba en GitHub.
3. Guarda una copia del index.html anterior como respaldo.
4. En el repositorio, abre index.html y pulsa el lápiz (Edit this file).
5. Selecciona todo el contenido anterior y reemplázalo por el contenido del nuevo index.html.
6. Pulsa Commit changes para guardar. Alternativamente, usa Add file > Upload files para subir el nuevo index.html a la raíz y confirma los cambios.
7. Comprueba que el archivo se llame exactamente index.html y quede en la raíz, no dentro de una carpeta.
8. Espera unos minutos y visita https://jmgtechpiura.github.io/. Si ves la versión anterior, pulsa Ctrl+F5.
